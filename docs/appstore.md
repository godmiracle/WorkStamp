## Long Description Draft

DayMark（印记相机）专注于一件事：让现场照片记录更可信、更清楚。

适合工程到场、巡检、外勤记录、装修跟进、学习打卡等场景。拍照后，照片可直接附带时间、地点、经纬度、海拔和工作进度信息，减少后续整理成本。

核心特性：

- 极简相机式首页，打开就能拍
- 时间、地点、经纬度、海拔水印
- 上班 / 下班状态标记
- 工作第 N 天记录
- 自定义模板文案与基础样式设置
- 照片保存到系统相册，并写入系统可识别的位置元数据

隐私说明：

- 默认仅在本地处理照片、定位和水印信息
- 不上传你的照片或位置数据到自建服务器

## Final Long Description

印记相机（DayMark）专注于一件事：让现场照片记录更可信、更清楚。

适合工程到场、巡检记录、外勤拍照、装修跟进、学习打卡等场景。拍完后，照片中可直接保留时间、地点、经纬度、海拔、上下班状态与工作第 N 天，后续回看和留档都更省心。

核心能力：

- 打开就拍的极简相机体验
- 时间、地点、经纬度、海拔水印
- 上班 / 下班状态标记
- 工作第 N 天自动计算
- 支持排除周末与中国法定节假日
- 工作天数前缀和基础样式可调整
- 保存到系统相册，并写入系统可识别的位置元数据

隐私边界：

- 默认仅在本地处理照片、定位和水印信息
- 不上传你的照片或位置信息到自建服务器
