# UI Guideline

## Design Direction

DayMark（印记相机）整体视觉应保持：

- 相机优先，而不是表单工具页感
- 信息可信、克制、清晰
- 接近系统相机，但保留自己的现场记录气质
- 毛玻璃、白字和高对比状态提示统一一套语言

## Color

### Primary

- 用途：关键交互、激活状态、品牌强调
- 当前方向：偏冷蓝色系，和图标主色一致

### Secondary

- 用途：次级按钮、信息辅助、分隔
- 当前方向：中性灰或低饱和玻璃灰

### Success

- 用途：状态正常、保存成功、定位稳定
- 当前方向：系统绿色附近，但避免太荧光

### Warning

- 用途：定位一般、权限待开启、等待状态
- 当前方向：暖黄或橙色

## Typography

- Title：页面主标题、主要面板标题
- Headline：功能组标题、状态面板主文案
- Body：设置说明、正文内容
- Caption：辅助说明、次要状态、标签

原则：

- 相机页避免出现过多大标题
- 预览页信息应更像 HUD，而不是设置表单

## Spacing

- 大区块使用更宽松间距
- 相机操作区按钮之间留出明确触控空间
- 水印信息行距保持紧凑，但不能挤到难读

## Corner Radius

- 主卡片：中大圆角
- 小胶囊：全圆角或接近全圆角
- 毛玻璃面板：统一圆角层级，不要混乱

## SF Symbols

- 优先使用白色 SF Symbols
- 语义必须直观，例如：
  - `camera.rotate`
  - `flashlight.off.fill`
  - `location`
  - `gearshape`
- 同一层级图标粗细尽量一致

## Material / Glass

- 设置面板和工具面板可使用液态玻璃风格
- 预览层不要被大面积厚重遮罩压住
- 最终照片水印当前以“白字直出”为主，不默认加底遮罩

## Dark Mode

- 深色模式下优先保证可读性和状态辨识
- 黑底区域要足够纯，避免灰雾感
- 图标、按钮和水印文字都要避开“看起来发虚”

## Consistency Rules

- 首页遵循“顶部轻工具 + 中间预览 + 底部主操作”
- 设置页遵循“少层级、强分组、可快速改关键项”
- 相同语义的状态文案不要反复换词

## Future Expansion

后续若增加多模板能力，建议先定义：

- 模板命名方式
- 模板预览缩略图规范
- 每套模板的字号、图标、对齐和留白规则
