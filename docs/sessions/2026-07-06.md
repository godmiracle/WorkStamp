# 2026-07-06

## Session Goal

把地点展示进一步调成更像现场水印相机的顺序：园区 / 商场 / 楼宇名在前，具体地址在后，同时避免重复拼接。

## What Changed

- 调整 `LocationService` 中 `CLGeocoder` 保底地址的拼装顺序，不再默认把详细地址放在前面
- 统一 `CLGeocoder`、`MapKit` 和附近 POI 补强三条地址链路的最终展示格式
- 增加地点名与详细地址的去重逻辑，避免出现“地点名重复一遍”或“被长地址淹没”的情况
- 完成一轮新方案真机构建并重新安装到 `哥谭之王`

## Notes

- 这轮不是继续追求更长的地址，而是让地点信息在照片里更容易被一眼识别
- 当前策略仍然遵守“低置信度不伪造 POI”，只有道路门牌时仍然会保留纯地址
- 如果详细地址里已经包含同一个园区 / 商场 / 楼宇名，会优先尝试去重后再拼装

## Suggested Next Step

优先用园区、商场、写字楼、普通街道各拍一张，确认“POI 在前”的观感是否已经明显更像你想要的成片。
