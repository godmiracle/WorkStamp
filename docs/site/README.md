# Public Pages

这个目录用于存放可公开托管的静态页面，方便填写 App Store Connect 所需链接。

当前包含：

- `support.html`
  最简支持页面
- `privacy.html`
  最简隐私政策页面

建议发布方式：

1. 使用 GitHub Pages 托管整个 `docs/site/`
2. 或复制到任意静态托管服务
3. 发布前记得替换页面里的联系邮箱占位文本

建议对应链接：

- Support URL: `https://your-domain/support.html`
- Privacy Policy URL: `https://your-domain/privacy.html`
