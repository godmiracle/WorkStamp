DayMark / 印记相机

隐私政策

生效日期：2026-07-02

印记相机（DayMark）重视你的隐私。本应用当前版本以本地处理为原则，不提供账号系统，也不会将你的照片、位置或工作记录上传到自建服务器。

1. 我们会使用哪些权限

相机权限：

  • 用于打开相机预览并拍摄照片。

定位权限：

  • 用于获取经纬度、海拔、地点名称与地址。
  • 用于把位置写入照片元数据，便于系统照片 App 显示地点标题与地图。

相册权限：

  • 用于将带水印照片保存到系统相册。

2. 我们会处理哪些信息

  • 拍摄时间
  • 地理位置
  • 海拔
  • 地址 / 地点名称
  • 用户设置项
  • 带水印照片

3. 信息如何存储

  • 设置项保存在你的设备本地。
  • 照片保存到你的系统相册。
  • 当前版本不建立远端用户档案。
  • 当前版本不上传照片、地点、位置或工作天数信息到自建服务器。

4. 权限拒绝后的影响

  • 拒绝相机权限后，应用无法拍照。
  • 拒绝定位权限后，应用仍可拍照，但地点、经纬度、海拔和位置元数据会缺失。
  • 拒绝相册权限后，应用无法将照片保存到系统相册。

5. 照片分享提醒

带水印照片可能直接包含时间、地点、经纬度和海拔信息；如果你分享这些照片，相关信息也可能一并被他人看到。

6. 第三方共享与追踪

  • 当前版本不接入第三方广告 SDK。
  • 当前版本不进行跨 App 或跨网站追踪。
  • 当前版本不向第三方出售你的个人信息。
