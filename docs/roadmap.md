# Roadmap

## Positioning

DayMark（印记相机）定位为长期维护的现场记录工具，而不是一次性 Demo。路线图优先围绕“记录可信度、拍摄效率、模板扩展性”展开。

## v1.0 MVP

目标：完成一个真机可用、打开就能拍的极简水印相机。

- 拍照
- 时间水印
- 上班 / 下班状态
- 经纬度
- 地点
- 海拔
- 工作第 N 天
- 基础水印位置 / 字号设置
- 照片元数据写入

## v1.1

目标：补足“可用性”和“可配置性”。

- 自定义模板文案
- 多套水印模板
- EXIF / 元数据体验继续完善
- Widget 快捷入口
- 更完整的真机验证记录

## v1.2

目标：增强系统集成和日常使用便利性。

- WeatherKit 天气信息
- 快捷指令支持
- iCloud 设置同步
- 更完整的导出与相册管理

## v2.0

目标：让产品从“记录工具”升级为“智能现场助手”。

- AI 地点识别 / 场景识别
- Apple Watch 辅助能力
- Live Activity
- 项目 / 场景级工作日管理

## Not In Scope For Now

- 社交分享
- 云端账号体系
- 复杂滤镜 / 美颜
- 跨平台 Android 同步开发

## Review Rhythm

- 每完成一轮较大功能后回看本文件
- 若版本目标发生明显变化，先更新这里，再更新 `todo.md`
