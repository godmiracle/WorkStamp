# Changelog

遵循简化版 Keep a Changelog。

## Unreleased

### Added

- 初始化 AI Native 项目模板结构。
- 增加 `AGENTS.md`。
- 增加 `docs/context.md`、`docs/architecture.md`、`docs/decisions.md`、`docs/todo.md`。
- 增加 `docs/README.md`、`docs/roadmap.md`、`docs/release.md`、`docs/appstore.md`、`docs/privacy.md`、`docs/ui-guideline.md`。
- 增加 `docs/testing.md`，用于沉淀真机测试范围、权限文案和测试记录模板。
- 增加 `docs/design/`、`docs/screenshots/`、`docs/assets/` 的归档说明。
- 增加 WorkStamp 的 MVP 产品定义与真机测试策略。
- 增加首页 / 设置页 SwiftUI 骨架。
- 增加工作第 N 天计算逻辑与基础单元测试。
- 增加真机相机预览、定位采集、水印绘制和相册保存链路。
- 增加接近现场水印相机的半透明灰底白字样式，并把 Bench 文案接入页面和照片水印。
- 增加上班 / 下班状态水印，以及 09:00 / 18:00 默认时间规则和设置入口。
- 增加液态玻璃风格的 App Icon，并提供亮色 / 暗色 / tinted 版本。
- 增加 `scripts/update_app_icon_variants.swift`，用于从主图标生成独立的深色和着色模式图标变体。
- 增加可编辑的工作日模板文案设置，支持把默认 `Bench` 改成自定义场景词。
- 增加中国法定节假日排除规则，并直接写死 `2026` 年放假与调休年度表。

### Changed

- 将模板根 README 改为 DayMark / 印记相机项目说明页。
- 将模板文档改为 WorkStamp / DayMark 项目文档。
- 设置页将“Bench 水印规则”收敛为更正式的工作天数/记录规则表达，并补充模板名称、实时预览、重置确认、节假日说明、四宫格位置和字号预览。
- 正式版设置页不再显示真机测试提示卡，避免保留 debug 信息观感。
- 工作天数模板从“只改 Bench”升级为“整段前缀可编辑”，并增加旧配置到完整前缀格式的一次性迁移。
- 首页调整为更接近真机相机的沉浸式布局，设置页调整为液态玻璃卡片风格。
- 预览水印改为逐行独立的高透明度玻璃遮罩，弱化整块灰底压屏感。
- 预览水印行距进一步收紧，最终照片水印改为无底遮罩的白字直出效果。
- 预览水印进一步对齐成片样式，去掉全部预览底遮罩，仅保留白字与阴影。
- 首页增加相机式最近照片缩略图入口，拍完后可直接在应用内查看成片。
- 底部控制区进一步贴近系统相机布局，并增加前后摄切换能力。
- 定位改为持续缓存优质坐标并按精度分级，地址优先使用更贴近 POI 的反查结果。
- 首页改为顶部轻设置、底部纯拍照控制的结构，进一步弱化工具页感。
- 顶部主卡片去掉重复设置入口，改为显示定位质量状态，信息层次更清晰。
- 首页进一步改成方案 A：顶部黑色轻工具条、中间纯预览、底部系统相机式主操作，并把水印细项收进底部抽屉。
- 首页状态进一步弱化：移除“相机就绪”常驻文案，只保留更轻的定位状态提示。
- 顶部闪光灯和倒计时接入真实拍照链路，左下角“地点”改为可查看地址与精度的定位面板。
- 应用品牌调整为中文名“印记相机”、英文产品名 `DayMark`，并同步更新图标资源命名与构建产物。
- 底部“模板”入口改为真实可用的快捷面板，可直接修改工作日水印里的模板文案。
- 预览水印改为白色 SF Symbols + 标题文字的简洁样式，并将最后一行左侧标题从模板词改成“备注”。
- 为排查 iOS 主屏图标缓存问题，切换到新的 `AppIconV2` 资源集，并将 build version 提升到 `2`。
- 深色图标进一步压暗边框和轮廓，让 dark 模式下一眼可辨。
- 深色图标再次强化到近黑边框方案，进一步拉开与亮色图标的主屏辨识度。
- 深色图标改为黑色底座方案：外围直接使用纯黑系圆角底，而不是继续加深原图边缘。
- 深色图标进一步裁掉下方白色功能区，只保留相机主体内容。
- 根据新的参考图，深色和着色图标回到完整构图方案：`Dark` 使用黑色底座，`Tinted` 使用统一蓝色着色底座。
- 将用户提供的成品图直接接入为 `Dark` 图标资源，不再通过脚本从亮色图自动生成该变体。
- 收口首版 App Store 文案、关键词和 5 张截图叙事，统一围绕“现场拍照留痕”表达。

### Fixed

- 保存到系统相册的照片现在会写入拍摄时间和定位元数据，照片 App 可按系统位置卡片与地图能力识别。
- 忽略 `kCLErrorDomain error 0` 这类临时定位未知错误，避免拍照时误弹“定位失败”提示。
- 设置页中的“中国法定节假日”开关不再是占位能力，已接入 `2026` 年真实工作天数与调休日判断逻辑。
