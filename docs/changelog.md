# Changelog

遵循简化版 Keep a Changelog。

## Unreleased

### Added

- 初始化 AI Native 项目模板结构。
- 增加 `AGENTS.md`。
- 增加 `docs/context.md`、`docs/architecture.md`、`docs/decisions.md`、`docs/todo.md`。
- 增加 WorkStamp 的 MVP 产品定义与真机测试策略。
- 增加首页 / 设置页 SwiftUI 骨架。
- 增加工作第 N 天计算逻辑与基础单元测试。
- 增加真机相机预览、定位采集、水印绘制和相册保存链路。
- 增加接近现场水印相机的半透明灰底白字样式，并把 Bench 文案接入页面和照片水印。
- 增加上班 / 下班状态水印，以及 09:00 / 18:00 默认时间规则和设置入口。
- 增加液态玻璃风格的 App Icon，并提供亮色 / 暗色 / tinted 版本。

### Changed

- 将模板文档改为 WorkStamp 项目文档。
- 首页调整为更接近真机相机的沉浸式布局，设置页调整为液态玻璃卡片风格。
- 预览水印改为逐行独立的高透明度玻璃遮罩，弱化整块灰底压屏感。
- 预览水印行距进一步收紧，最终照片水印改为无底遮罩的白字直出效果。
- 预览水印进一步对齐成片样式，去掉全部预览底遮罩，仅保留白字与阴影。
- 首页增加相机式最近照片缩略图入口，拍完后可直接在应用内查看成片。
- 底部控制区进一步贴近系统相机布局，并增加前后摄切换能力。
- 定位改为持续缓存优质坐标并按精度分级，地址优先使用更贴近 POI 的反查结果。

### Fixed

- 保存到系统相册的照片现在会写入拍摄时间和定位元数据，照片 App 可按系统位置卡片与地图能力识别。
